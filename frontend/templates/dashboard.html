How to Interpret

Weighted F1 is the primary metric because the three classes are imbalanced. It balances precision and recall across all classes.

Random Forest vs Decision Tree: RF achieves higher F1 by averaging many trees (reduces variance). DT is more interpretable — you can trace a single path from root to leaf.

Baseline outperforms on synthetic data because labels were partly derived from the CVSS score. This is expected and is discussed as a limitation.

Low-class F1 is lower because there are far fewer Low samples. class_weight="balanced" helps but can't fully compensate.
